Data setup and backup

Import your local data ZIP once into an empty cloud database. This preserves your emails, attachments, saved reviews and existing AI cache. Importing does not call Gemini.

Existing database records cannot be replaced through this page. Imported review names remain self-reported; importing does not verify their identity or approve documents.

Limits: ZIP 30 MB, each file 10 MB, expanded total 50 MB. Use the supplied Export-Data.ps1 script to prepare the ZIP.
